## 重要坑（后续天复用）
1. **hf-mirror 必须设 HF_HUB_DISABLE_XET=1**：xet 协议经镜像会下载 0 字节空文件，报 JSONDecodeError。
2. **huggingface_hub 下载在本机会被 safe-delete 钩子拦截**（删 .lock 文件失败）。模型文件已用 curl 直接下载到 `models/bge-small-zh-v1.5/`，脚本优先从本地目录加载，避免再走 hub 下载。
3. HF_ENDPOINT 必须在 import sentence_transformers 之前设置。
4. LLM 实测未跑：用户稍后自行创建 .env 填 DEEPSEEK_API_KEY 后运行 `python scripts/test_llm.py`。
